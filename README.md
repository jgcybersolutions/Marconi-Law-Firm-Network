# 🚧 Challenges

One of the biggest goals of this project was creating a secure environment where users only had access to the resources required for their role.

This involved designing user accounts, assigning security groups, configuring shared folders, and implementing appropriate NTFS permissions while maintaining a clean and scalable Active Directory structure.
