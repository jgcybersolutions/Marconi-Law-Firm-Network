# Marconi Law Firm Enterprise Network

Enterprise network implementation project for a fictional 10-user law firm using Windows Server 2025 and Active Directory.

## Project Highlights

- Designed a complete enterprise LAN
- Configured Windows Server 2025
- Installed Active Directory Domain Services
- Created 10 Active Directory user accounts
- Created security groups for departments
- Configured shared folders and NTFS permissions
- Assigned static IP addresses
- Designed a professional network topology
- Selected enterprise hardware and software
- Produced complete project documentation
- Delivered a client presentation

## Project Summary

This project involved designing and implementing an enterprise network for a 10-user law firm. The environment includes Windows Server 2025, Active Directory, user and group management, shared folder permissions, static IP addressing, and enterprise networking best practices.

The project also includes complete documentation and a narrated walkthrough demonstrating the final implementation.
