# 📂 Documentation

This folder contains the written documentation created throughout the Marconi Law Firm Enterprise Network project.

## What's Included

📄 Project Report

The complete project report covering:

- Project planning
- Enterprise network design
- Hardware recommendations
- Windows Server implementation
- Active Directory configuration
- Documentation and deliverables

## Why It Matters

Technical documentation is just as important as building the environment itself.

One thing I've learned while working on projects is that if someone else can't understand what you built, maintaining it becomes much harder.

This report shows not only what I built, but how I planned it and why I made the decisions I did.

Thanks for checking it out!
